# Actividad 3

La Actividad 3 contiene dos ejercicios de interfaz grafica implementados en
Python con Tkinter.

## Ejercicios

| Ejercicio | Archivo | Contenido |
| --- | --- | --- |
| 3.1 | `Ejercicio1.py` | Ingreso de cinco notas y calculo del promedio, desviacion estandar, nota mayor y nota menor. |
| 3.2 | `Ejercicio2.py` | Calculo del volumen y la superficie de un cilindro, una esfera y una piramide. |

## Ejecucion

Ejecuta el archivo correspondiente desde esta carpeta:

```bash
python Ejercicio1.py
python Ejercicio2.py
```

En el ejercicio 3.1 se calcula la desviacion estandar poblacional. En el
ejercicio 3.2 se considera que la base de la piramide es cuadrada. El dato
solicitado para la piramide es el area de esa base, en cm^2; la altura y el
apotema se ingresan en cm.
