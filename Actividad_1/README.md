## Ejercicio 1 — Edades de la familia

A partir de la edad de Juan se calculan las edades de Alberto, Ana y la mamá.

El archivo [Ejercicio1.py](Ejercicio1.py) resuelve el problema de dos formas:
una versión estructurada (entrada, proceso y salida) y otra usando la clase `Edades`.

## Ejercicio 2 — Operación de suma

Se sigue una secuencia de operaciones sobre las variables `x`, `y` y `suma`
para obtener el resultado final.

El archivo [Ejercicio2.py](Ejercicio2.py) usa la clase `OperacionSuma`.

## Ejercicio 3 — Salario de un empleado

Un empleado trabaja 48 horas a la semana a razón de $5.000 la hora y tiene una
retención en la fuente del 12,5% del salario bruto. Se calculan el salario bruto,
la retención y el salario neto.

El archivo [Ejercicio3.py](Ejercicio3.py) usa la clase `Empleado`.

## Ejercicio 4 — Cuadrado y cubo de un número

Se lee un número y se obtienen su cuadrado y su cubo.

El archivo [Ejercicio4.py](Ejercicio4.py) usa la clase `Numero`.

## Ejercicio 5 — Área y circunferencia de un círculo

Dado el radio de un círculo, se calculan el área y la longitud de la circunferencia.

El archivo [Ejercicio5.py](Ejercicio5.py) usa la clase `Circulo`.

## Cómo ejecutar

```bash
python Ejercicio1.py
```
